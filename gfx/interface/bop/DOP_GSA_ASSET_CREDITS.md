# Academy project image

DOP_GSA_project_1.png is a lossless format conversion of “0 series Yurakucho 19670505.jpg”, photographed by Roger Wollstadt on 5 May 1967. It is used as a project reference image, not presented as a photograph of fictional Guangdong.
