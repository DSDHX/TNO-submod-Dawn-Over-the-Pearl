## 重建阶段机制触发点（保持作者原布局）

以下只说明各机制挂载在哪个作者国策，不重排坐标、前置或分支：

1. `GNG_focus_temporary_relief`：恢复立法会。
2. `GNG_focus_foothold`：恢复地区 GUI，并纳入海南、钦州、湛江组件。
3. `GNG_focus_leave_ruins_behind`：开启岭南建设总署，只开放广西高速公路网与广西实业院。
4. `GNG_focus_new_products_old_friends`：按作者原位置恢复产品周期，不承担阶段接棒。
5. `DOP_GNG_recon_foundation`：开启三微米冷战。
6. `DOP_GNG_recon_backwardness_disaster`：开启科学院。
7. `DOP_GNG_recon_no_time_to_turn`：恢复珠江奇迹，并切换为中华民国对比。
8. `DOP_GNG_recon_opening_ceremony`：作为作者布局中的最终节点，载入大国策树。

`DOP_GNG_recon_grand_wall_weak_foundation` 保持作者原有坐标与前置关系，但不接入任何广东大剧院机制；当前只显示冻结说明。

## 法案冻结区

以下分支及其前置段不做效果装填，直至作者提供一段式法案国策设计：

- 民族条例、政商关系、工会、地方公权、金融与货币改革分支。
- 木棉花医疗保险、广东新课纲、寻找粮仓及其共同前置建设段。
- 社团再安置分支及其前置灰色经济段。
- 国家防卫条例及其前置、后续军务段。
- 开局树内现有的单国策法案事件只视作历史资源，不扩写法案机制。
