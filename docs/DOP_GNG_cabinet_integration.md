## 生效位置

- `common/scripted_effects/DOP_GNG_cabinet_effects.txt`：五套内阁的角色招募、行政长官任命、部长职务及路线同步。调用任一 `DOP_GNG_apply_cabinet_<路线>` 可立即安装对应内阁；重复调用同一路线不会重复任命。
- `common/on_actions/DOP_GNG_flow_on_actions.txt`：每日按照当前结局国策树同步一次内阁。既有加载结局树的调试决议同样适用；已进入结局树的旧存档在下一次每日更新时安装内阁。
- `common/scripted_effects/DOP_GNG_postwar_effects.txt`：五个结局状态效果同时调用内阁安装。其生成源 `tools/implement_dop_content.py` 已同步此调用，避免重新生成时丢失。
- `localisation/simp_chinese/DOP_GNG_cabinet_l_simp_chinese.yml`：五篇行政长官介绍、二十篇部长介绍及姓名，UTF-8 BOM。

稻叶和田村使用已有的大头像；山下、三田、何善衡、出井使用已有立绘生成 65×67 内阁小头像。其他人沿用 TNO 头像。既有部长在同一职务上的 TNO 特质继续使用；新职务只有对应槽位标记，没有新增数值加成。

小头像保持原比例和完整头部，透明留边。预览见 [内阁小头像对照图](DOP_GNG_cabinet_portrait_preview.png)（第一张为 TNO 大森宽，后四张为新增小头像）。

行政长官的政治角色采用 TNO 现有子意识形态：盛田为企业家长制，稻叶为殖民政府，田村为军政府。后两项是为使文本中的行政长官真正上任所作的实现选择，原文没有指定子意识形态。没有改动政党支持率。

## 重建

在 submod 根目录运行：

```powershell
python tools/import_dop_cabinet.py
```

生成内阁效果、本地化、GFX 注册及四张 DDS 小头像。运行时需 Pillow；游戏使用生成文件，无需 Python。
